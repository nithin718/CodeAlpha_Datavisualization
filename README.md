# 📊 Data Visualization of Highest Grossing Films

## Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship – Task 3: Data Visualization**.

The objective of this project is to transform a dataset of the world's highest-grossing films into meaningful visual representations using Python. By creating charts and graphs, the project highlights trends, distributions, and key insights that are difficult to observe from raw data alone.

## Project Objectives

* Visualize the highest-grossing films dataset using Python.
* Identify patterns and trends through graphical representation.
* Improve understanding of movie revenues and release timelines.
* Present insights in a clear and easy-to-interpret format.

## Dataset

The dataset used in this project contains information about the world's highest-grossing films collected from Wikipedia.

The main attributes include:

* Rank
* Peak Position
* Movie Title
* Worldwide Gross
* Release Year

Before visualization, the dataset was cleaned by converting the **Worldwide Gross** column into a numeric format suitable for analysis.

## Visualizations Included

### 1. Top 10 Highest Grossing Films

A bar chart comparing the worldwide earnings of the top ten highest-grossing movies.

### 2. Movies Released by Year

A line chart showing the number of highest-grossing films released in different years.

### 3. Distribution of Worldwide Gross

A histogram illustrating how worldwide earnings are distributed across the dataset.

### 4. Movies by Decade

A pie chart displaying the proportion of highest-grossing films released in each decade.

* `Task3_DataVisualization.ipynb` – Complete visualization notebook

## Key Insights

* Modern films contribute significantly to the list of highest-grossing movies.
* A small number of films generate exceptionally high worldwide revenue compared to the rest.
* The majority of highest-grossing films belong to the 2000s and 2010s.
* Visual analysis makes it easier to identify revenue patterns and historical trends.

## How to Run

1. Clone or download this repository.

2. Install the required dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Open `Task3_DataVisualization.ipynb`.

4. Run all cells in sequence.

5. The charts and visualizations will be generated automatically.
